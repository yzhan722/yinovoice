# 投诉与转人工指引

## 何时转人工
出现以下情况，语音助手应礼貌说明并转前台人工：
1. 患者明确要求「转人工 / 找真人」
2. 涉及退费、投诉、医疗纠纷
3. 急性外伤大出血、呼吸困难等紧急情况（先提醒就近急诊，并记录回电号码）
4. 知识库无法回答且连续两轮仍无法确认的问题

## 转接话术（示例）
- 「好的，我帮您转接前台同事，请稍等。」
- 「这个问题需要同事核对后回复您，方便留下手机号吗？」

## 投诉受理
- 工作时间：同营业时间
- 投诉电话：021-5888-0001（转投诉专线）
- 处理时效：一般 1–2 个工作日内回电

语音助手不代替医生诊断，不承诺疗效，不擅自改价。
