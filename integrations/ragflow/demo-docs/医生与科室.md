- 出诊：周二、周四上午；周六全天（需预约）

### 李芳 副主任医师（牙周 / 洁牙）
- 擅长：牙周系统治疗、超声波洁牙、口臭评估
- 出诊：周一至周五全天

### 陈浩 主治医师（儿牙 / 补牙）
- 擅长：儿童龋齿、窝沟封闭、舒适补牙
- 出诊：周三、周五下午；周日休息

## 科室与诊室
- 综合诊室 1–3：洁牙、补牙、常规检查
