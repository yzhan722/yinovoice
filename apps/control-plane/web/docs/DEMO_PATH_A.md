## 10 分钟演示顺序

1. **登录** → 进入工作台  
2. **工作台**  
   - 说明待处理回拨数量与「+N」  
   - 说明今日/本周/待确认预约  
   - **现场完成一条跟进**（开始处理 / 完成）  
   - 指出通话曲线为「演示指标」，点「接入位」看预留说明  
3. **回拨任务** → 默认待处理列表，标记完成一条  
4. **预约结果** → 对照今日与待确认  
5. **我的实例** → 打开「太平洋口腔 · 新北前台」概览（机构信息 + 通话接入位）  
6. **通话记录** → 展示「接入位已就绪」面板（**不要承诺已接通话**）  
7. **知识库**（可选、一笔带过）→ 菜单最下方，非本阶段重点  

## 严禁 / 避免

- 不要把演示通话数字说成真实接通量  
- 不要演示运营端（除非内部调试模板）  
- 不要深入 RAG / 知识库上传细节
