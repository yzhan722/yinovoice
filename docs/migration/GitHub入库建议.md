# GitHub 入库建议

更新日期：2026-08-13

## 当前判断

本地仓库已具备可审查的项目结构，但在测试、静态检查、类型检查和最终报告完成前，不建议推送。复核时远程无分支引用，本地 `main` 的提交不能视为已发布。

## 推荐方式

- 在 GitHub Desktop 确认当前登录的是有权协作的个人账号；不需要切换成所有者 `yzhan722`。
- 推荐创建新分支并通过 Pull Request 做首次入库审查，即使当前账号有直接推送权限。
- 请所有者或管理员确认 rulesets、branch protection、审批和 CI 要求。
- 不使用强制推送，不替换目标 `.git`，不复制任何源仓库 `.git`。

## 推荐提交拆分

1. 原始迁移基线（当前已有本地提交）。
2. 治理规则、状态、索引、复核与验收报告。
3. 后续旧路径修复和部署去重应分别提交，并单独验证。
