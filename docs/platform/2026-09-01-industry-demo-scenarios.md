# 合成行业演示案例（2026-09-01）

用于网页实时语音切换的虚构机构。不含真实客户、患者、地址或可拨打热线。

导入后可在「实时语音」下拉框切换。通话中预约/回拨走隐藏 Tool（`check_availability` / `create_appointment` / `create_callback`）。

## 如何导入

1. 「我的实例」→ **导入行业演示**（幂等；已存在则跳过）。
2. 或重启 Platform API：Demo 租户会在启动时补齐同一批实例、排期项目与知识条目。

## 边界

- 价格、库存、具体老师/医生是否在岗：不编造，改为回电确认。
- 急重症、车辆安全隐患：引导停驶/急诊，不闲聊。
- 号码与地址均为合成演示字段。
